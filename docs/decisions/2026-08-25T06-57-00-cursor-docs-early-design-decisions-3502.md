## 1. Decision

1. 毎日自動生成する音声の目安尺は約 5 分とする。30 分毎日は採らない。
2. 尺の根拠は要求「無料〜月おおよそ 1000 円」と、当時の TTS 単価試算（30 分×毎日 ≒ 予算超過、5 分×毎日 ≒ 予算内）である。
3. 価格表・plan 名は Decision や README に写経しない。単価が変わって予算を割る場合は、尺か vendor かをその session で再決定する。課金 plan の code 固定は `2026-08-17T17-41-59` の Rejected に従う。

## 2. Reason

要求の費用上限が、機能より先に生成量を拘束する。尺を決めずに「全部盛り」すると、後から品質以外の理由で破綻する。

## 3. Rejected

1. 30 分×毎日を初期の標準尺にする案
2. 予算を無視して品質・尺だけを先に最大化する案
3. 円建ての予算額を Adapter 定数や contracts に埋め込む案
