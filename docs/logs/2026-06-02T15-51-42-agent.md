## 重要な決定

**CI fail の根本原因**
`pnpm-lock.yaml` を `googleapis` / `@google/genai` 追加後にコミットしていなかった。`--frozen-lockfile` の CI 環境では lockfile が package.json と不一致でインストール自体が失敗する。今後は依存追加後に `pnpm install` → lockfile を必ずコミットする。

**Drive appProperties 124バイト制限の回避策**
Google Drive API の `appProperties` は key+value 合計 124 バイト上限。manuscript JSON（数KB）は直接格納不可。2つの選択肢があった：
1. `description` フィールドに埋め込む（〜8192文字、日本語で危険）
2. JSON ファイルを別途 Drive にアップロードし、音声ファイルの `appProperties.jsonFileId` でポインタのみ持つ ← **採用**

option 2 が Drive の設計思想（ファイルシステムとしての参照）に沿っており、サイズ制限から完全に自由になる。音声ファイルアップロード → JSON ファイルアップロード → `files.update` で音声に jsonFileId を紐付ける 3ステップ構成に変更した。

**`pnpm run orchestrate` が `.env.local` を読まない問題**
Next.js の自動読み込みは `next` コマンド経由でのみ有効。Node.js 直実行では `.env.local` が無視される。`--env-file` フラグ（Node.js v20.6+ 組み込み）で依存追加なしに解決した。
