## 重要な決定

### ダーク系テーマの選定理由
Podcast appらしい視覚的アイデンティティを確立するため、ダーク背景（`#030712`）＋パープル〜シアングラデーション＋ダークカード＋ホバーアニメーションを採用。
- **トレードオフ**: カラーパレット・アニメーションを追加することで実装量増（⬆️ UI polish）が一時的に増加するが、最終的にはMVP完成度（完成度）向上のため正当化される。
- **代替案**: Neutral な light mode →却下（podcastアプリとして個性に欠ける、既存競合アプリとの差別化不足）

### `next/font` 導入による外部fetch削除
Google Fonts CDNからの外部fetch（ボトルネック：往復遅延 + 3rd-party risk）を廃止し、`next/font/google`でビルド時Interフォント埋め込みに変更。
- **効果**: 0 CLS（Cumulative Layout Shift）、preload対応、SSR速度改善
- **実装**: `layout.tsx`で`display: swap`を指定し、フォント読み込み中も代替フォント表示（ページ遷移スムーズ）

### Suspense + Skeleton による UX改善
エピソード一覧fetch中に真っ白な画面を表示しないよう、Suspense boundary でskeletonを先行レンダー。
- **効果**: 体感速度向上、loading状態が視覚的に分かる
- **実装**: `page.tsx`でSuspenseでwrap → `<EpisodeListSkeleton>`を fallback に設定。skeleton自体がダーク系デザインに統一されているため違和感なし。

### ページ遷移中の loading.tsx 追加
episode/[id]へ遷移時、ページ読み込み完了までskeleton画面（pulse animation）を表示。
- **効果**: ユーザーが「クリックが反応している」ことを確認できる（UX改善）
- **実装**: `loading.tsx`を`episode/[id]/`に新規作成。Next.js の自動Suspense wrap 機能を活用。
